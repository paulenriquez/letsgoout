# Emoji catalog

`emoji-data.json` is the English Emojibase catalog from
`emoji-picker-element-data` 1.8.0, generated from `emojibase-data` 17.0.0.

- Package: https://www.npmjs.com/package/emoji-picker-element-data/v/1.8.0
- Source: https://github.com/nolanlawson/emoji-picker-element-data
- SHA-256: `e5408f6c06fda053316e98ee811aae2774876809d409bb5f2d9186e60b48e0c3`
- License: Apache-2.0; see `LICENSE` in this directory.

The browser uses the annotations, tags, and shortcodes for search. The Go
backend builds its authoritative allowlist from the `emoji` values and their
skin variants, excluding group 2 composition components.
